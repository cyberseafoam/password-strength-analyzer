# Password-Analyzer
This is a project I did for one of my Computer Science classes. It tests how good a password is and gives a checklist and suggestions to make it better.

Contains the main code as password_analyzer.py and the web interface code as app.py

Steps:
1. Download the two python files
2. In the terminal, install Streamlit: 
3. In the terminal, type: python -m streamlit run app.py
4. Now you can test passwords!
